## ✨ 游戏理念

「表扬」是被记录的爱。这款游戏把家庭教育中最自然的动作——**表扬孩子**——变成一套可视化的成长体系：

- 两个孩子，各养一只宠物，同屏成长、互相见证
- 家长每次看到值得表扬的进步，点一下就记录下来
- 宠物获得经验 → 升级 → 进化形态，孩子亲眼看到"好习惯让宠物长大"
- 照顾宠物（喂食/玩耍/洗澡）本身就是一堂责任课

## 🎮 玩法说明

| 系统 | 说明 |
|------|------|
| 🌟 **表扬加分** | 9 种表扬类型（认真学习/帮忙家务/懂礼貌/按时作息/独立吃饭/坚持运动/诚实分享/爱护宠物/特别表扬），不同分值，可附 40 字表扬语，自动记入成长日记 |
| ⬆️ **等级进化** | Lv.1–20，经验升级；四个成长阶段：**幼崽期 → 成长期 → 壮年期 → 传奇期**，宠物体型变大、长出披风与皇冠 |
| 🍖 **日常照顾** | 喂食/玩耍/洗澡恢复饱食、心情、清洁、精力四项状态，带真实时间冷却，防止"刷分" |
| 🛍️ **金币商店** | 金币来自表扬与照顾；可买零食礼盒（恢复状态）和 4 种永久装扮（礼帽/围巾/墨镜/皇冠） |
| 📅 **每日打卡** | 每天首次进入领金币，连续打卡 3/7/15/30 天有额外大奖 |
| 🏆 **成就墙** | 12 种成就徽章，每只宠物独立收集 |
| 📖 **成长日记** | 最近 300 条成长记录，含表扬原文 |
| 👑 **领先者** | 总经验更高的一方显示领先小皇冠，良性激励 |
| 💾 **本地存档** | localStorage 自动保存，支持 JSON 导出/导入备份 |

## 🐱 六种宠物

橘猫 · 柴犬 · 兔子 · 熊猫 · 狐狸 · 小龙

全部由 **SVG 参数化绘制**（无任何图片资源）。每只宠物都是**会动的卡通角色**：

- **常驻生命感**：呼吸起伏、自动眨眼、摇尾巴、耳朵偶尔抖动、皇冠闪光
- **随机待机小动作**：每 2-6 秒随机表演——歪头卖萌、蹦一下、东张西望、打喷嚏、打瞌睡、打哈欠、委屈叹气
- **表情随状态变化**：开心（弯月笑眼）/ 饥饿（星星渴望眼+张嘴）/ 困倦（闭眼+Zzz）/ 脏兮兮（眯眼+汗滴）/ 委屈（泪眼+掉泪）
- **互动表演**：表扬时跳舞💃、喂食时点头吃起来、玩耍时大跳、洗澡时抖水，还会冒爱心/音符/星星粒子
- **舞台展示**：头像光圈呼吸 + 地台投影 + 小草小花装饰 + 背景飘云闪烁星星

## 🛠 技术特点

- **零依赖单页应用**：原生 HTML/CSS/JS，无框架、无构建、无外部请求，克隆即可玩
- **模块化结构**：

```
pet-buddy/
├── index.html          # 页面骨架（欢迎 / 设置 / 主屏）
├── css/style.css       # 暖白极简设计系统 + 动效 + 响应式
├── js/
│   ├── data.js         # 宠物 / 表扬类型 / 商店 / 成就 / 等级曲线
│   ├── art.js          # SVG 宠物绘制引擎（分层结构：头/耳/尾/眼/身）
│   ├── anim.js         # 宠物动作系统（待机随机动作 + 情绪表演 + 粒子）
│   ├── audio.js        # WebAudio 程序化音效（无音频文件）
    ├── game.js         # 核心状态机与存档
    ├── ui.js           # 渲染层 / 弹窗 / 动效
    └── main.js         # 启动与事件绑定
```

- **动效**：CSS 呼吸/眨眼/摇尾/皇冠闪光、随机待机动作库（歪头/跳跃/喷嚏/哈欠/叹气……）、表扬跳舞、喂食点头、洗澡抖水、升级全屏横幅、金币飞舞、五彩纸屑
- **音效**：WebAudio 实时合成（表扬琶音 / 升级号角 / 金币叮当 / 洗澡水声……）
- **移动端适配**：≤700px 自动切换为竖排布局，安全区适配
- **存档安全**：结构校验 + 自动修补，导入失败不影响现有进度

## 🚀 本地运行

无需安装任何东西：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：起个本地服务（推荐）
python3 -m http.server 8080
# 访问 http://localhost:8080
```
