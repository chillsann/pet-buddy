## ✨ 游戏理念

「表扬」是被记录的爱。这款游戏把家庭教育中最自然的动作——**表扬孩子**——变成一套可视化的成长体系：

- 两个孩子，各养一只 **3D 宠物**，同屏成长、互相见证
- 家长每次看到值得表扬的进步，点一下就记录下来
- 宠物获得经验 → 升级 → 进化形态，孩子亲眼看到"好习惯让宠物长大"
- 照顾宠物（喂食/玩耍/洗澡）本身就是一堂责任课
- **进度永久保存**：换设备也能用存档码一键迁移

## 🐱 六种宠物

橘猫 · 柴犬 · 兔子 · 熊猫 · 狐狸 · 小龙

全部由 **基础几何体程序化拼装**（无外部模型文件）：

- **3D 形象**：球体身体、锥形耳朵、管状尾巴、真实眼睛高光、粉腮红、胡须
- **常驻生命感**：呼吸起伏、自动眨眼、摇尾巴、耳朵抖动、轻微浮动
- **拖拽互动**：按住拖动可 360° 旋转，松手后自动缓摆
- **情绪表演**：表扬时跳舞、喂食时点头进食、玩耍时大跳、洗澡时抖水、升级时旋转
- **表情随状态变化**：饥饿张嘴、困倦半闭眼、委屈……配合漂浮表情粒子
- **舞台展示**：柔光 + 接触阴影 + 地台 + 小花小草 + 飘云闪烁星星

## 🛠 技术特点

- **单页应用**：原生 HTML/CSS/JS + Three.js（3D 渲染），无构建步骤，克隆即可玩
- **模块化结构**：

```
pet-buddy/
├── index.html          # 页面骨架（欢迎 / 设置 / 主屏）
├── css/style.css       # 暖白极简设计系统 + 动效 + 响应式
├── js/
│   ├── vendor/three.min.js  # Three.js r128（本地打包，无 CDN 依赖）
│   ├── data.js         # 宠物 / 表扬类型 / 商店 / 成就 / 等级曲线
│   ├── art.js          # SVG 宠物绘制（2D 回退）
│   ├── anim.js         # 2D 动作系统（回退模式）
│   ├── pet3d.js        # 3D 宠物引擎：建模 / 灯光 / 阴影 / 拖拽 / 动画
│   ├── audio.js        # WebAudio 程序化音效（无音频文件）
│   ├── game.js         # 核心状态机与存档
│   ├── ui.js           # 渲染层 / 弹窗 / 动效
│   └── main.js         # 启动与事件绑定
```

- **3D 技术**：MeshStandardMaterial 柔光材质、半球光 + 主光 + 补光 + 轮廓光、PCFSoftShadowMap 接触阴影、程序化几何体建模、`requestAnimationFrame` 动画状态机、指针拖拽旋转
- **性能**：像素比上限 2、离场 `dispose()` 释放显存、增量更新避免重建场景
- **兼容**：WebGL 不可用时自动回退 SVG 2D 角色，功能完全一致
- **动效**：CSS 呼吸/眨眼/摇尾、3D 待机动作、升级全屏横幅、金币飞舞、五彩纸屑
- **音效**：WebAudio 实时合成（表扬琶音 / 升级号角 / 金币叮当 / 洗澡水声……）
- **移动端适配**：≤700px 自动切换为竖排布局，安全区适配
- **存档安全**：结构校验 + 自动修补；自动保存 + 存档码 + JSON 导出三重备份

## 🚀 本地运行

无需安装任何东西：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：起个本地服务（推荐）
python3 -m http.server 8080
# 访问 http://localhost:8080
```
